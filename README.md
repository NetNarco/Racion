# Рацион на неделю — Клон квиза (Без оплаты и подписки)

![License](https://img.shields.io/badge/license-MIT-green.svg)
![React](https://img.shields.io/badge/React-18-blue.svg)
![Status](https://img.shields.io/badge/status-active-success.svg)

Полнофункциональный клиентский клон сервиса составления индивидуальных рационов питания (`quiz.legkost-test.online/racion`).

> **Главное отличие:** В оригинальном сервисе после прохождения анкеты требуется платная подписка (пейволл). Здесь **весь результат** (меню на 7 дней, КБЖУ, список покупок и рецепты) открывается сразу и **абсолютно бесплатно**, без регистрации, серверов и отправки данных в сеть.

---

## 🌟 Основные возможности

- **Индивидуальный расчет КБЖУ**: Формула Миффлина — Сан Жео с учетом пола, возраста, роста, веса и уровня физической активности.
- **Меню на 7 дней**: 104 разнообразных блюда (завтраки, обеды, ужины, перекусы) с учетом типа питания (всеядный, пескетарианец, вегетарианец, веган), аллергенов и стоп-листов.
- **Любимые продукты**: Выбор из 80 позиций по отделам супермаркета — блюда с ними ставятся в меню в первую очередь.
- **Список покупок**: Автоматический расчет по базовой корзине розничных сетей (Магнит, Пятёрочка, Лента, Ашан, Перекрёсток) с округлением до упаковок.
- **Адаптивный интерфейс**: Поддержка десктопов и мобильных устройств, переключаемая дневная и ночная темы (🌙/☀️).
- **Автономность**: Всё приложение может работать как один готовый файл (`dist/racion-besplatno.html`), открывающийся двойным щелчком без сервера и интернета.

## 📂 Структура проекта

```text
├── index.html               # Версия с ES-модулями (требует HTTP-сервер)
├── build.mjs                # Скрипт сборки в один автономный HTML-файл
├── dist/
│   └── racon-besplatno.html # Готовый автономный файл для запуска без сервера
├── assets/
│   ├── css/                 # Дизайн-система, темы и шрифты
│   └── js/                  # Логика квиза, движок расчета и UI-компоненты
└── tools/                   # Набор тестов и проверок инвариантов
```

## 🚀 Как запустить

### Вариант 1: Быстрый запуск (без сборки и сервера)
Просто откройте в браузере файл:
[`dist/racion-besplatno.html`](dist/racion-besplatno.html)

### Вариант 2: Запуск исходной версии для разработки
Для работы с `index.html` необходим локальный веб-сервер (так как браузеры блокируют ES-модули по протоколу `file://`):

```powershell
# Установка зависимостей (если требуется)
npm install

# Запуск локального сервера
npx serve .
```

## 🌐 Деплой на GitHub Pages

Вы можете опубликовать этот проект за пару минут через **GitHub Pages**:

1. Создайте репозиторий на GitHub и загрузите файлы проекта.

3. В качестве источника (`Source`) выберите ветку `main` (или `master`) и папку `/ (root)` или `/dist` (если загружаете готовый `racion-besplatno.html`).
4. Сохраните — ваш сайт станет доступен по ссылке GitHub Pages!
